# Repository Conventions

## Homework ordering

- Homework folders use zero-padded numbers for HW1-HW9 so GitHub's
  lexicographic file tree displays them in numeric order:
  HW01, HW02, HW03, HW04, HW06, HW07, HW08, HW09, HW10, HW11, HW12, ...
  Keep HW10 and above unpadded. When adding HW12, append it after HW11;
  never insert homework out of order.
- The repository has no HW05 folder. Keep the gap; do not renumber later homework.
- README tables and section order use the display labels HW1, HW2, ...,
  but links, commands, and GitHub Pages URLs must use the actual folder names
  (e.g. `homework/HW01/README.md`, `https://.../homework/HW01/`).
- The canonical ordered view is `homework/README.md` and `homework/HW11/README.md`.
- Do not rename existing folders or remove the zero padding; it would break
  links, GitHub Pages URLs, and the file-tree order.
